# Employee Attrition Analytics

## Project Overview
Analysis of employee attrition patterns across department, job role,
tenure, compensation and workload.

## Analysis
- Data cleaning
- Attrition KPIs
- Early-tenure attrition
- Department analysis
- Job-role analysis
- Income-band analysis
- Overtime analysis
- Statistical association testing
- Interactive Streamlit dashboard

## Dashboard
Run:

streamlit run dashboard/app.py

## Note
Observed statistical associations do not establish causation.
